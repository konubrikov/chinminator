Chinminator 1.7 — Qwen-Image 2.1, FLUX 3, Lightning и Pruna

БЫСТРЫЙ ЗАПУСК
1. Распакуйте ZIP в постоянную папку на локальном диске.
2. Windows: дважды нажмите Start.cmd. Mac: Start.command.
3. Выберите модель. Enter сохраняет последнюю модель.
   1 — Qwen 2.1, 2 — FLUX 3, 3 — Lightning 4-step, 4 — Pruna 6-step v0.2.
   При первом запуске автоматически устанавливаются отдельный Python 3.12,
   зависимости, ComfyUI и выбранные модели. Python, Git и Homebrew вручную не нужны.
4. Дождитесь READY. Серверы запускаются автоматически. Подтвердите установку панели,
   если Creative Cloud запросит её. При необходимости откройте Chinminator.ccx вручную.
   Для установки панели через CCX Adobe UXP Developer Tool не нужен.
5. Photoshop → Плагины → Chinminator. Фото должно быть RGB, 8 бит/канал.
   Оставьте окно запуска открытым. Test.cmd / Test.command проверяет реальную генерацию.
6. Для следующих сеансов снова запускайте Start. При выборе другой модели скачиваются
   только недостающие веса. Stop завершает серверы этой установки, если нет активной ретуши.

ТРЕБОВАНИЯ WINDOWS
Windows 10/11 x64, NVIDIA Turing или новее, минимум 8 ГБ VRAM и 16 ГБ системной RAM
(32 ГБ рекомендуется), актуальный драйвер NVIDIA с CUDA 13. Photoshop 24.2+ и Creative Cloud.
На 8 ГБ используются INT8 и выгрузка частей модели на CPU. На 24+ ГБ VRAM и 64 ГБ RAM
выбираются BF16-веса. 8 ГБ — минимум профиля, а не гарантия обработки любого размера.

ТРЕБОВАНИЯ MAC
macOS 14+, Apple Silicon без Rosetta, минимум 24 ГБ unified memory, включая M4 Pro 24 ГБ.
Photoshop 24.2+ и Creative Cloud. На 24–48 ГБ — INT8, на 64+ ГБ — BF16 diffusion/encoder.
У FLUX 3 на Mac prompt upsampler INT8; текстовый энкодер и VAE работают на CPU,
генерация — на MPS GPU. Качественный режим доступен, но может потребовать swap или дать OOM.
Пакет не подписан Apple и не notarized. macOS может запросить разрешение на открытие.
Если Finder не запускает .command, из папки пакета в Terminal: bash scripts/setup_macos.sh
Реальная генерация на MPS НЕ ПРОВЕРЕНА на этом Windows-компьютере. Запустите Test.command
на целевом Mac. Тест CUDA не подтверждает совместимость и скорость MPS.

ДИСК И МОДЕЛИ
Оставьте минимум 45 ГБ свободного диска; для BF16 — 80 ГБ. Для двух моделей нужно больше.
Qwen остаётся основным режимом. Standard подбирает INT8/BF16 по памяти.
Q4_K_M — дополнительный облегчённый Qwen; он может быть медленнее Standard.
Lightning и Pruna используют базу Qwen Standard и добавляют один адаптер.
Lightning скачивает 67 МБ, Pruna — 688 МБ. Для этих адаптеров вход в Hugging Face не нужен.
Масштаб области исходный. Число шагов фиксировано, поэтому «Максимум деталей» недоступен.
Для FLUX 3 обычный режим — 16 шагов, исходное разрешение области.
«Максимум деталей» — 16 шагов и генерация области в масштабе 1,5× по каждой стороне.
Итоговый кадр остаётся исходного размера. 1,5× требует больше памяти, может быть медленнее
Qwen и меняет не только детали, но и форму/оттенки. Для Qwen максимум — прежние 40 шагов.
Авто Qwen выбирает 28/40 шагов по размеру области. Скрытого уменьшения пикселей нет.
Промпты Qwen и FLUX сохраняются отдельно. Смена модели происходит при запуске сервера.

ДОСТУП К FLUX 3
Нужен собственный аккаунт Hugging Face и принятие условий именно этого репозитория:
https://huggingface.co/black-forest-labs/flux-3-image-klein-comfy
Установщик открывает страницу модели и запрашивает READ token скрытым локальным вводом.
Создание токена: https://huggingface.co/settings/tokens — нужен доступ к gated-моделям.
Токен хранится только в обычном локальном кэше Hugging Face. В установочных архивах его нет.
401 означает отсутствие действующего входа; 403 — условия ещё не приняты этим аккаунтом
либо у токена нет доступа. Исправьте доступ и повторите Start. Для Qwen вход не нужен.

ОСТАНОВКА И ОБНОВЛЕНИЕ
Install запускает тот же установщик. Choose-model позволяет сменить также Standard/Q4;
сначала используйте Stop. Не запускайте два установщика одновременно в одной папке.
Stop завершает только процессы, запущенные данным комплектом, и не прерывает GPU-задачи.
Чужой ComfyUI или старый API на портах 8188/8765 закройте перед запуском новой установки.
После установки не перемещайте папку Python. При обновлении сначала остановите старый API.
Можно перенести веса vendor/ComfyUI/models; .venv и .python между компьютерами не копируйте.
Логи: work/api.log, work/comfy.log. Выбранный аппаратный профиль: hardware-profile.json.

ОПЕРАЦИИ PHOTOSHOP
Для Actions нужен Photoshop 25+. После переключения модели заново сохраните настройки
кнопкой «Для Обработчика изображений». Записанные UXP-операции сохраняют старый промпт:
при необходимости перезапишите шаг. Инструкции по Actions и Image Processor — README.md.
Фотографии обрабатываются локально. Интернет нужен для установки зависимостей и моделей.
