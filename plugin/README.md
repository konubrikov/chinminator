# Chinminator — Qwen-Image 2.1

В UXP Developer Tools добавьте manifest.json и загрузите плагин в Photoshop.
Нужны RGB, 8 бит/канал и локальный API http://localhost:8765.
Сервер запускается через scripts/start_server.bat из корня проекта.

Анализ показывает метрики и маску без генерации. Применение использует Qwen-Image 2.1 через ComfyUI и создаёт новый слой. Пакет обрабатывает открытые документы. Сила всегда максимальная, мягкий переход задаёт маска подбородка и шеи с дополнительным запасом по контуру. Исходные пиксели вне маски сохраняются.

Установка и требования описаны в корневом README.md.

Кнопки запуска закреплены над прокручиваемыми настройками. По умолчанию включено «Обработать каждое фото»; режим «Авто» может пропустить изображение по результатам анализа. Статус этапа и причина пропуска/ошибки показаны под кнопками. Проверено в Photoshop 27.8: запуск из панели, генерация через CUDA на RTX 4070 Ti SUPER и вставка результата новым слоем.

Кнопка «Редактировать промпт…» открывает отдельное окно. «Сохранить» применяет текст к следующим запросам без пересборки и перезапуска сервера; текст хранится в папке данных плагина (retouch-prompt.txt). «Отмена» не меняет сохранённый текст. «По умолчанию» восстанавливает исходный текст в редакторе; для применения нажмите «Сохранить».

Маска уточняется локальной моделью MediaPipe SelfieMulticlass: кожа лица и тела внутри области выбранной челюсти/шеи, без несвязанных участков кожи. Одежда, волосы и фон исключены из основы маски; небольшой запас и растушёвка наружу позволяют заменить исходный силуэт. Пиксели внешнего периметра рабочего кропа сохраняются из оригинала. Сегментация выполняется на CPU, генерация Qwen — на CUDA/GPU. Модель сегментации автоматически загружается при первом анализе в server/models, затем работает локально.
Маска дополнительно охватывает нижнюю часть щёк и прилегающую кожу нижней части ушей. Верхняя граница поднимается по бокам, сохраняя верх лица вне области редактирования.

Настоящий latent inpainting: исходный кроп кодируется через VAEEncode, маска передаётся через SetLatentNoiseMask в KSampler. Вне маски ComfyUI восстанавливает исходный latent на каждом шаге. Используется существующая Qwen-Image 2.1, без замены checkpoint на отдельную inpainting-модель. Кроп имеет контекстный запас 60% размера области с каждой стороны (ограничен краями фотографии); внешние 16 пикселей входа модели защищены от генерации. Финальное наложение сохраняет оригинальные пиксели вне маски, компенсируя погрешность VAE. Проверено на synthetic-04: 40 шагов, 49 секунд, 0 изменений вне маски; 11 контрактных тестов пройдены.

По умолчанию включён быстрый режим: 28 шагов, кроп до 1024 px. Флажок «Максимум деталей (медленнее)» возвращает 40 шагов и кроп до 1536 px. На synthetic-04 с seed=42 и прогретой RTX 4070 Ti SUPER: 48.2 с → 21.9 с. Это сравнение настроек с разным разрешением, а не гарантия идентичной детализации. Исходный размер итогового изображения, маска inpainting и запас контекста сохраняются. Повторные запросы используют стабильные имена входов, позволяя ComfyUI кэшировать неизменившиеся узлы.


ОПЕРАЦИИ PHOTOSHOP (ACTIONS), PHOTOSHOP 25+
1. Запустите серверы и загрузите панель Chinminator.
2. Выберите режим, порог, качество и промпт в панели.
3. Окно → Операции: создайте операцию или включите запись существующей.
4. В Chinminator нажмите «Записать шаг в операцию» и остановите запись в Photoshop.
   При записи фото не обрабатывается; записывается только один шаг плагина.
5. Запустите операцию на нужном RGB-документе, 8 бит/канал.
   Шаг ждёт ответа модели и вставки слоя Chinminator Fixed, затем передаёт управление
   следующему шагу операции. При ошибке сервера операция останавливается.

Промпт, режим, порог и качество сохраняются внутри шага. Изменения панели после записи
не меняют уже записанную операцию: для других настроек запишите новый шаг.
Шаг всегда обрабатывает текущий документ. «Пакет: все открытые документы» и
«Результат рядом с оригиналом» на него не влияют. Размер области остаётся исходным.
Режим «Авто» может пропускать фото по анализу; режим «Обработать каждое фото» запускает
ретушь при найденном лице. Отсутствие лица считается пропуском, а не ошибкой.
Для папки фотографий используйте Файл → Автоматизация → Пакетная обработка и эту операцию.
Сохранение и закрытие результата добавьте отдельными шагами Photoshop по своей схеме.
На каждом компьютере необходимы установленный/загруженный Chinminator и работающие серверы.
В Photoshop 24.x обычная панель доступна, но запись шага требует Photoshop 25+.

Проверено на Photoshop 27.8 / Windows: запись через панель Операции, воспроизведение
на другом тестовом документе, реальная GPU-генерация и вставка нового слоя.
Документация API Adobe:
https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/action-recording


ИСПРАВЛЕНИЕ ПАКЕТНОГО РЕЖИМА — 1.4.1
Обновите одновременно сервер и панель: перезапустите API и перезагрузите плагин.
Существующий шаг Chinminator перезаписывать не требуется.
Для пакета используйте меню Photoshop Файл → Автоматизация → Пакетная обработка.
Источник — отдельная папка, операция — ваш шаг Chinminator. Для сохранения результата
задайте соответствующие шаги и выходную папку; не используйте исходную папку как выходную.
Не вызывайте UXP-операцию из синхронного ExtendScript app.doAction/executeAction:
такой вложенный вызов блокируется в Photoshop до выполнения плагина.
Запуск Batch через штатное меню проверен на всех пяти synthetic-01…05 в Photoshop 27.8.
У каждого файла появился слой Chinminator Fixed. Размер 1254×1254 сохранён;
вне маски изменено 0 пикселей во всех пяти результатах. Отчёт: BATCH-VALIDATION.json.
Mac-пакет содержит те же исправления; реальная проверка выполнена на Windows/CUDA.
