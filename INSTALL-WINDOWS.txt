Chinminator — Windows / NVIDIA CUDA

Пакет содержит исходники и установщик; зависимости и модели скачиваются при установке.
Нужны Windows 10/11 x64, Python 3.12 с Python Launcher (python.org), Git for Windows,
совместимый драйвер NVIDIA CUDA 13, Photoshop 24.2+, Adobe UXP Developer Tool,
интернет и минимум 40 ГБ свободного диска. Проверено на RTX 4070 Ti SUPER 16 ГБ / RAM 64 ГБ.
Минимальная конфигурация Windows с 8 ГБ пока требует уточнения: RAM или VRAM.

1. Распаковать в постоянную папку; запустить Install.cmd.
2. После установки запустить Start.cmd. Не закрывать сервер во время работы.
3. Test.cmd запускает реальную тестовую ретушь; результат work/smoke-before-after.png.
4. В Adobe UXP Developer Tool добавить plugin/manifest.json, выбрать Photoshop, Load.

Авторежим: фактический кроп до 2048 px — 28 шагов, рабочий размер до 1024 px;
более крупный кроп — 40 шагов, до 1536 px. Маленький кроп не увеличивается.
Флажок «Максимум деталей» оставляет ручной режим 40 шагов / 1536 px.
Исходный размер результата сохраняется. Маска inpainting ограничивает генерацию на каждом шаге.

После обновления нужно остановить прежний API и запустить сервер из новой папки.
Установщик не меняет политики PowerShell и не требует включения неизвестных расширений.
