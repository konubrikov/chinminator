# Chinminator 1.7 — Qwen 2.1, FLUX 3, Lightning и Pruna

Инструкция по установке и запуску для Windows и Mac находится в START-HERE.txt (INSTALL-1.7.txt).
Start устанавливает недостающие компоненты и запускает выбранную модель. Панель устанавливается через Chinminator.ccx.

ОПЕРАЦИИ PHOTOSHOP (ACTIONS), PHOTOSHOP 25+
1. Запустите серверы и загрузите панель Chinminator.
2. Выберите режим, порог, качество и промпт в панели.
3. Окно → Операции: создайте операцию или включите запись существующей.
4. В Chinminator нажмите «Записать шаг в операцию» и остановите запись в Photoshop.
   При записи фото не обрабатывается; записывается только один шаг плагина.
5. Запустите операцию на нужном RGB-документе, 8 бит/канал.
   Шаг ждёт ответа модели и вставки слоя Chinminator Fixed, затем передаёт управление
   следующему шагу операции. При ошибке сервера операция останавливается.

Промпт, режим, порог и качество сохраняются внутри шага. Изменения панели после записи
не меняют уже записанную операцию: для других настроек запишите новый шаг.
Шаг всегда обрабатывает текущий документ. «Пакет: все открытые документы» и
«Результат рядом с оригиналом» на него не влияют. Размер области остаётся исходным.
Режим «Авто» может пропускать фото по анализу; режим «Обработать каждое фото» запускает
ретушь при найденном лице. Отсутствие лица считается пропуском, а не ошибкой.
Для папки фотографий используйте Файл → Автоматизация → Пакетная обработка и эту операцию.
Сохранение и закрытие результата добавьте отдельными шагами Photoshop по своей схеме.
На каждом компьютере необходимы установленный/загруженный Chinminator и работающие серверы.
В Photoshop 24.x обычная панель доступна, но запись шага требует Photoshop 25+.

Проверено на Photoshop 27.8 / Windows: запись через панель Операции, воспроизведение
на другом тестовом документе, реальная GPU-генерация и вставка нового слоя.
Документация API Adobe:
https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/action-recording


ИСПРАВЛЕНИЕ ПАКЕТНОГО РЕЖИМА — 1.4.1
Обновите одновременно сервер и панель: перезапустите API и перезагрузите плагин.
Существующий шаг Chinminator перезаписывать не требуется.
Для пакета используйте меню Photoshop Файл → Автоматизация → Пакетная обработка.
Источник — отдельная папка, операция — ваш шаг Chinminator. Для сохранения результата
задайте соответствующие шаги и выходную папку; не используйте исходную папку как выходную.
Не вызывайте UXP-операцию из синхронного ExtendScript app.doAction/executeAction:
такой вложенный вызов блокируется в Photoshop до выполнения плагина.
Запуск Batch через штатное меню проверен на всех пяти synthetic-01…05 в Photoshop 27.8.
У каждого файла появился слой Chinminator Fixed. Размер 1254×1254 сохранён;
вне маски изменено 0 пикселей во всех пяти результатах. Отчёт: BATCH-VALIDATION.json.
Mac-пакет содержит те же исправления; реальная проверка выполнена на Windows/CUDA.


ОБРАБОТЧИК ИЗОБРАЖЕНИЙ — 1.5.0
1. Перезапустите сервер через Start и перезагрузите обновлённую панель.
2. Выберите режим, промпт и качество в панели и нажмите «Для Обработчика изображений».
   Это сохраняет настройки для сценария. После изменения настроек нажмите кнопку снова.
3. Один раз откройте Файл → Сценарии → Обзор и выберите
   scripts/Install-ImageProcessor-Action.jsx из постоянной папки проекта.
   Будет установлена операция Chinminator Image Processor → Retouch.
4. В Файл → Сценарии → Обработчик изображений выберите папку исходников,
   отдельную папку результатов и форматы сохранения. Включите «Выполнить операцию»:
   набор Chinminator Image Processor, операция Retouch.
   Не добавляйте в эту операцию обычный UXP-шаг Chinminator: вложенный вызов зависает.
5. Нажмите «Выполнить». Сценарий ждёт GPU-ретуши каждого фото и добавляет новый слой;
   затем штатный Обработчик сохраняет и закрывает результат. PSD сохраняет слои.

Сценарий использует последние сохранённые настройки панели. Записанный UXP-шаг
для обычной Пакетной обработки по-прежнему хранит собственный снимок настроек.
Не переносите JSX в Presets Photoshop: он находит сервер относительно папки scripts.
После перемещения проекта удалите только набор Chinminator Image Processor и снова
запустите установщик операции. Сервер должен работать из этой же папки проекта.
Поддерживаются RGB 8 бит/канал; отсутствие лица в авторежиме даёт пропуск.
Ошибка сервера/таймаут останавливает сценарий с сообщением; автоматического CPU fallback нет.
Контекстная рамка увеличена: запас вокруг маски 100% вместо 60% её большего размера.
Рамка ограничена краями фото; пиксели области остаются в исходном разрешении.
Большая рамка может увеличить расход памяти и время генерации.

Adobe Обработчик выполняет операцию отдельно для каждого выбранного формата.
JPEG + PSD означают две генерации на фото, с возможными различиями результата.
Для одного прохода выберите только PSD, затем экспортируйте готовые PSD в JPEG
отдельным запуском Обработчика с выключенным «Выполнить операцию».

Проверено 1.5.0: штатный Обработчик изображений Photoshop 27.8 / Windows / CUDA,
все 5 synthetic-фото, JPEG и PSD (10 GPU-проходов по 40 шагов). Размер 1254×1254,
в PSD исходник и слой Chinminator Fixed; вне маски 0 изменённых пикселей.
Отчёт: IMAGE-PROCESSOR-VALIDATION.json. На macOS этот запуск не проверялся.
